Instruções para Exclusão de Dados

LAD Prospecção

O LAD Prospecção guarda as conversas comerciais com a LAD Sistemas pelo WhatsApp e os dados do estabelecimento no CRM, conforme a Política de Privacidade.

Como solicitar a exclusão de dados

Para pedir a exclusão das suas conversas e dos seus dados de contato, envie a solicitação pelo próprio WhatsApp comercial ou pelo site ladsistemas.com.br, informando o número de telefone usado no contato. A LAD Sistemas confirma a identidade do solicitante e remove os dados em até 30 dias, exceto o que precisar ser mantido por obrigação legal ou contratual. O número fica numa lista de bloqueio para não ser contatado de novo.

Esta página é efetiva a partir de Outubro/2026.
