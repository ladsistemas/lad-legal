Política de Privacidade

Lad Cardápio Mesa (br.com.lad.cadapio.mesa) — atualizada em novembro de 2026

O Lad Cardápio Mesa é um aplicativo da Lad Sistemas Software LTDA ("LAD") instalado em tablets que ficam nas mesas de bares e restaurantes que utilizam o sistema LadFood. Nele, o cliente do estabelecimento consulta o cardápio, faz pedidos para a sua mesa ou comanda, acompanha a conta e pode responder a uma pesquisa de satisfação. Esta política explica quais dados o aplicativo trata, para quê e com quem eles são compartilhados, nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

1. Quem é responsável pelos dados

O aplicativo só funciona conectado ao sistema LadFood de um estabelecimento. Os dados do atendimento (pedidos, comandas, conta e respostas da pesquisa) pertencem ao estabelecimento, que é o controlador desses dados. A LAD atua como operadora, fornecendo o software e o suporte técnico.

2. Dados tratados pelo aplicativo

  • Dados do pedido: produtos escolhidos, opcionais, observações e o número da mesa ou comanda. São enviados ao sistema LadFood do estabelecimento para registrar, preparar e cobrar o pedido. O cliente não precisa se identificar para fazer pedidos.
  • Pesquisa de satisfação (opcional): as notas, o comentário, o e-mail (necessário para enviar a pesquisa) e, se o cliente quiser informar, o telefone. São enviados ao estabelecimento para que ele avalie o atendimento e, quando o cliente pedir, entre em contato.
  • Câmera: usada somente quando o cliente ou o atendente pede para ler o QR Code da comanda. A imagem é processada no próprio aparelho apenas para decodificar o código; nenhuma foto ou vídeo é gravado ou enviado. O aparelho memoriza apenas qual câmera (frontal ou traseira) foi escolhida.
  • Dados técnicos do aparelho: o identificador do dispositivo fornecido pelo Android (ANDROID_ID), o nome e a versão do aplicativo e informações de conexão (tipo de rede, tempo de resposta e falhas de comunicação). São enviados ao servidor LadFood do estabelecimento para identificar quais tablets estão em uso, diagnosticar problemas de rede e permitir o suporte técnico.
  • Configurações locais: endereço do servidor, empresa, mesa fixa, comanda em uso e uma cópia do cardápio para acelerar a abertura, armazenados apenas no aparelho.

O aplicativo não coleta localização, contatos, fotos, microfone nem identificadores de publicidade, e não contém bibliotecas de publicidade ou de análise de terceiros.

3. Para que usamos os dados

Exclusivamente para operar o atendimento do estabelecimento: exibir o cardápio, registrar e enviar pedidos, mostrar a conta, receber a pesquisa de satisfação e prestar suporte técnico. Não usamos os dados para publicidade nem criamos perfis de usuários.

4. Onde os dados ficam e com quem são compartilhados

Os pedidos e a pesquisa são enviados ao servidor LadFood do estabelecimento, normalmente instalado na rede local do próprio estabelecimento. O aplicativo também consulta a nuvem LadFood, operada pela LAD, para obter os banners e o tema visual do estabelecimento e, quando o servidor local muda de endereço, para encontrá-lo novamente; nessas consultas é enviado apenas o código do estabelecimento, sem dados de clientes.

A LAD não vende nem compartilha esses dados com terceiros. O acesso fica restrito ao estabelecimento e, quando necessário para suporte, à equipe da LAD. Os dados só são fornecidos a autoridades quando exigido por lei ou ordem judicial.

5. Por quanto tempo os dados são mantidos

Os dados armazenados no tablet permanecem até que a configuração seja alterada, os dados do aplicativo sejam limpos ou ele seja desinstalado. Os dados enviados ao sistema do estabelecimento são mantidos pelo período definido pelo estabelecimento e pelas obrigações legais e fiscais aplicáveis.

6. Seus direitos

Pela LGPD, o titular pode solicitar confirmação, acesso, correção, anonimização, portabilidade ou eliminação dos seus dados. Clientes de um estabelecimento devem fazer a solicitação ao próprio estabelecimento, que é o controlador. Estabelecimentos podem contatar a LAD pelo e-mail abaixo, e responderemos dentro dos prazos legais.

7. Público

O aplicativo é instalado e configurado pelo estabelecimento para uso no salão. Ele não é direcionado a crianças e não coleta intencionalmente dados de menores de 13 anos.

8. Alterações nesta política

Esta política pode ser atualizada para refletir mudanças no aplicativo ou na legislação. A versão vigente estará sempre publicada nesta página, com a data de atualização no topo.
